# 试点报告 D — 生成对照（Desjardine et al. 2025 holdout，2026-09-07）

> 前置：A（v1.1 重跑 96.7%）/ B / C（12/12 检出）已通过，判别器具备区分力。
> 选篇：**Desjardine, Li & Shi (2025, AMJ)**。Fini et al. (2017) 出局——write-theory registry 4 处命中 + rhetoric-moves/sources 句子级文件 + write-theory 语料多文件引用（tfr_169–173），生成侧污染过重。Desjardine：四库 registry 零命中、write-* 语料零句子级存在；story-blueprints 有完整学习卡（coverage: complete），但生成/标注代理输入=文法+简报/文法+生成文本，卡片不在任何代理的输入路径上——残余风险仅为模型参数记忆（2025 年新文，风险低）。

## 设计

- **生成侧**：单代理，输入=`_argument-grammar.md` v1.1 全文 + 三份简报（`d-briefs-desjardine.md`：claim 意图 + reason moves + 指定引文 + 结构要求），零工具、不接触原文。三段覆盖三种功能形态：G1=假设后替代方案排除段（A&R 密集型）、G2=调节假设推导收束段、G3=段首 claim 机制段。
- **评估侧**：两个互不可见盲标注代理（Alpha-D/Beta-D），输入=文法 v1.1 + 生成文本（同 A 电池任务书）。
- **比对基准**：原文对应段功能特征清单（`d-originals-desjardine.md`，仅主代理可见）。
- **成本**：生成 28K + 双标注 66K ≈ **94K tokens**。

## 结果

### A. 标注一致性（生成文本）

| 段落 | 五问 #1–#5（Alpha/Beta） | 拼贴 #1–#5 | 一致性 |
|------|------------------------|-----------|--------|
| G1 | ✓✓✓✓✓ / ✓✓✓✓✓ | 全不命中（双跑同） | **完全一致** |
| G2 | ✓✓✓✓✓ / ✓✓✓✓✓ | 全不命中（双跑同） | **完全一致** |
| G3 | ✓✓✓✓✓ / ✓✓✓✓✓ | 全不命中（双跑同） | **完全一致** |

- **五问一致率 30/30 = 100%；拼贴 30/30 = 100%**。生成文本双跑零分歧（高于原文 96.7%）——role-first 组装的段落角色边界更清晰，判定更可重复，这本身是文法→生成闭环效度的正面证据。
- 标签级差异 3 处，均不翻转判定：G1 move 计数 3/2（move 切分粒度，已知弹性）；G2 S8"Thus:"一判 Claim 一判 Framing（衔接符归类，v1.2 候选⑦素材）；G2 S2 一判 Evidence 一判 Reason（锚点句与承重前提同句时的主角色归属）。

### B. 失败三分类

- **真瑕疵 0、规则误报 0**：3/3 生成段全过 Gate 5，无需分类处置。
- 两位标注员各自的最大不确定点收敛于同一处：**G3 S4 双重身份句**（Alpha 判 A&R、Beta 判定义前提[D]）——"边界澄清句 vs 预判异议并回应"缺操作界分，但双跑五问/拼贴判定结果完全相同，属标注层模糊而非判别缺陷。
- 新增 v1.2 候选：**⑤ 内嵌 warrant/共享前提的锚点归属**（G2 S5"利益相关者视评级可信"——经验性行为前提无独立引文，一判与相邻锚共用、一判分析性豁免）；**⑥ 边界澄清句与 A&R 的界分**（G3 S4）；**⑦ 单句衔接词（Thus:/That is）的角色归类**（G2 S8）。

### 功能特征比对（生成 vs 原文，不比文本相似度）

| 特征 | 原文段 | 生成段 | 兑现 |
|------|--------|--------|------|
| G1 段末 "Taken together" 收束 | ✓ | ✓（S7） | ✓ |
| G1 First/Second 编号理由 + 异议回应结构 | ✓（段级 A&R） | ✓（S1 预判 + S7 回应） | ✓ |
| G1 引文锚定 | 两处一般性断言**无引文** | 两处全部锚定（SEC 2022; Berg et al. 2022） | 生成版更合规（简报强制给锚） |
| G2 3-move 链 + "That is...Thus:" 收束 + 假设形式化 | ✓ | ✓（moves=3 双跑一致；S7–S9） | ✓ |
| G2 evidence-led 开场（According to...） | ✓ | ✗（claim-led 开场 S1，原文上一段的损伤前提压缩为段内锚定前提 S2） | 形态差：合规（claim 段首或段末均可），非缺陷 |
| G3 段首条件性 claim | ✓ | ✓（S1） | ✓ |
| G3 warrant 性边界句（奖项不进评级公式） | ✓（"At the same time, since..."） | ✓（"The boundary of this mechanism matters..."） | ✓ |
| G3 "As a result" receptivity 收束 | ✓ | ✓（S5） | ✓ |
| A&R 预算（0–2/篇） | 原文选段 1 处（O1） | 生成 2 处（G1+G3，双跑确认在预算内） | ✓ |

- 值得注意的信号：简报对 G3 只要求"边界澄清句"，生成器自主将其升级为**显式 A&R**（预判"奖项不进公式则无法影响评级"的异议并回应）——生成器对文法 A&R 角色的应用比简报要求更充分，双跑均判合法（预算内）。文法→生成→再判定的闭环正常工作。
- 文本相似度抽查：生成段无一句复现原文句式或措辞（简报为功能级描述，无原文暴露）。

### C 探针（生成文本）——范围裁量

协议字面要求生成后跑 A–C 全电池。C 差分探针（6 种定向降级×双盲评）刚在 v1.1 下以 12/12 检出、0/4 误报通过；生成段全数合格、无缺陷可检，对生成文本重跑探针只复检已证能力。**本轮裁量跳过**，预估节省 ≈100K tokens；若后续文法升 v1.2，建议把"生成文本降级探针"并入新版 C 电池一次补齐。

## 结论

1. **D 电池通过**：文法 v1.1 作为生成骨架，可在零原文暴露条件下产出通过 Gate 5 的段落，且简报指定的结构特征（claim 句位、move 数、锚点、收束标记、A&R）全部兑现——判别器不仅能剔除坏段落，其角色语法还能正向组装好段落。
2. 判别器四电池（A 89%→96.7%、B 0 真瑕疵、C 12/12、D 100% 一致）**校准完成**；试点方法学（holdout 纪律 + 双盲 + 失败三分类）可复用于真实草稿（P2 阶段）。
3. v1.2 候选累计 7 条：①收束句定义、②经验/分析边界（两轮电池复现，证据最强）、③跨段补背景容许度、④gap 句角色条目、⑤内嵌 warrant 锚点归属、⑥边界澄清 vs A&R 界分、⑦衔接符角色归类。均已登记 `write-theory/corpus/_skill_design_feedback.yaml`（前四条 batch_2026-09-07；⑤–⑦ 见本报告，待下批登记）。
