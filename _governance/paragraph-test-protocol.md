# Paragraph Test Protocol — 段落论证体检（黄金论文校准判别器）

> **目标**：用顶刊已发表文本校准论证判别器（write-introduction Gate 5 / `_argument-grammar.md` 五问+拼贴判据），为 P2 生成测试提供可信的尺子。
> **三陷阱对策**：段落级判定规避循环输入与多解性（审查测试无需输入提取）；蒸馏污染对审查类测试影响弱——生成类测试（D）仅用 holdout。

## 一、采样规则

- **Holdout 定义**：论文未出现在 write-theory / write-introduction / write-methods / write-results 任一 `_evidence_registry.yaml` 的 source_papers；且不属于召回域（DV/IV 含召回/产品伤害）。避开语料密集子领域（strategy 联盟/治理、TMT 符号管理）更稳。
- **回归对照**（可选）：已蒸馏论文 1–2 段，用于语料/规则变更后的回退检测（用法④）。
- **段落选取**：每篇 5–6 个论证型段落（Theory why-chain 段、Tension/Stakes 型段优先）；framing 段（Hook、纯背景）单列不进五问判定池。
- **试点规模**：1 篇 × 5–6 段；扩展批次再叠加。

## 二、四项电池

### A. 标注一致性（先测尺子）
1. 同一批段落文本（**去署名、去期刊信息**）交两个独立标注运行（两个互不可见的子代理，同规则同任务）。
2. 每段输出：论证角色序列（claim / reason / evidence / warrant / A&R 句位标注）+ framing 豁免判定 + 五问逐项 ✓/✗ + 拼贴判据 5 条逐项命中与否。
3. 比对两遍结果：角色序列一致率、五问判定一致率。**两遍分歧的段落 = 规则模糊点**，逐条修 `_argument-grammar.md` 措辞（就地改并在文内标注修订）。

### B. 黄金回测（测误报）
1. 对黄金段落执行 Gate 5 全检查（五问 + 拼贴判据 5 条）。
2. 每个失败案例三分类：
   - **真瑕疵**：发表文本确实违反论证标准（Booth 会同意）——审查器正确，顶刊不完美；
   - **规则误报**：判据把合法写法判为缺陷——修判据措辞（走 design-feedback-loop）；
   - **风格差异**：领域/期刊惯例不同——标注为风格项，不计入 gate 误报，但要记录。
3. 指标：核心维度误报率（误报 ✗ 数 / 判定总数）。**>20% = Gate 5 判据过严**，先修尺子再谈生成测试。

### C. 差分探针（测检出）

对黄金段落做六种定向降级（每种对应一个文法要素），逐一检验判别器是否抓住：

| # | 探针 | 降级手法 | 应命中 |
|---|------|---------|--------|
| P1 | claim 失踪 | 主题句移段尾或删除 | 五问#1 / 拼贴#4 无主段落 |
| P2 | reason 断链 | 删一个推理环节、保留结论 | read-my-mind / 环节计数 |
| P3 | evidence 孤儿 | 删某条证据所支撑的理由，或塞无锚引文 | 拼贴#2 |
| P4 | warrant 悬空 | 插入与任何 reason→claim 对无关的一般原则句 | 拼贴#3 |
| P5 | 引用列队 | 相邻两句改写为平行罗列式引用 | 拼贴#5 |
| P6 | A&R 断半 | 承认段删回应半句 | 五问#5 |

指标：per-probe 检出率。漏检 = 该要素判据需加严或 gate 未接线。

### D. 生成对照（可选，holdout only）

对 holdout 段落仅提供输入（claim 意图 + 所依据的发现），生成后跑同一 A–C 电池；与原文段落的功能特征清单比对（不比文本相似度）。

## 四、反馈通道

测试发现 → `_skill_design_feedback.yaml` observation（走 `distill-theory-exemplar/references/design-feedback-loop.md` 门控，测试结果=observation 不直接改规则）；判据措辞修正就地改 `_argument-grammar.md`。**回归集**：已蒸馏论文段落的判定结果留档，语料/规则变更后重跑对比。
