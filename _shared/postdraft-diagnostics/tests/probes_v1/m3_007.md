## Results

We first use them in a mediation test, exploring if the relationship between TMT political ideology and recall counts is explained by a reduction in adverse events.

We reveal that adverse event count is positively associated with recall count ( $\beta = 0.018$; p < 0.01), and TMT political ideology continues to be negatively associated with recall count ( $\beta = -0.110$; p < 0.001), although to a lesser degree, when adverse event count is included in the model.

If so, this would lend further credibility to the notion that more liberal TMTs initiate fewer recalls because their firms make higher-quality products.
