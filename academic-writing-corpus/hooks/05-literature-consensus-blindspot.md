# Literature Consensus + Blind Spot Hook

## 功能定义
先建立一个被文献广泛接受的结论（consensus），然后迅速揭示这个共识忽视了某个重要的连带后果或利益相关方。这种hook将读者的注意力从"共识是否正确"转移到"共识的不完整性"。

## 句法模板

**模板 A（共识→被忽视的后果）**：
```
[Extensive research / A large body of work] has [established / demonstrated / shown] that [core consensus finding] (e.g., [citation 1]; [citation 2]).
[Second sentence: what this consensus implies for the primary actor].
Yet this literature has [largely / almost entirely] overlooked [consequential effect on secondary actor / downstream consequence / hidden cost].
[Third sentence: why this omission is theoretically consequential].
```

**模板 B（受益者→受害者视角转换）**：
```
Scholars have devoted considerable attention to [how X benefits Y], establishing that [mechanism] (e.g., [citations]).
[Second sentence: this body of work treats the benefits to [Y] as the natural endpoint of analysis].
However, [what happens to Z] — the [target / recipient / secondary party] — remains [unexamined / undertheorized].
[Third sentence: this blind spot matters because...].
```

## 例句（来自 MVP30）

**来源**：Those Closest Wield the Sharpest Knife（来自 memory mapping）

> "Ingratiation benefits the ingratiator, but what about the target?"

**改写模板**：
> "[Extensive research] has [established] that [core phenomenon] [benefits / enhances / improves] [primary actor] (e.g., [citation 1]; [citation 2]). [This work / These studies] treat [primary actor]'s [gain] as the [natural / logical] endpoint of analysis. However, [what happens to secondary actor / what are the downstream consequences] remains [largely unexamined / undertheorized]. This omission matters because [theoretical reason]."

## 使用场景

| 维度 | 建议 |
|------|------|
| **Outlet 偏好** | 通用型，特别适合 micro-OB, interpersonal dynamics, stakeholder theory 论文 |
| **理论类型** | **关系性理论 / 网络外部性 / 多重利益相关者视角** — 任何存在"一方行动影响多方"的情境 |
| **前提条件** | 共识必须真实存在且被广泛引用；盲点必须确实被忽视（不能是已有大量文献讨论过的） |
| **风险** | 如果盲点其实已被讨论，会被 reviewer 质疑文献综述不全面 |

## 关键技巧：视角转换的戏剧性

这种hook的冲击力来自**视角的突然转移**：
- 先让读者站在 ingratiator 的位置（"我如何讨好上级"）
- 然后突然切换到 target 的位置（"但上级会怎样？"）
- 这种转换制造了"aha moment"

**操作化建议**：
1. 第一段建立共识（从 primary actor 视角）
2. 第二段用"But what about...?"或"Yet this literature has overlooked..."切换视角
3. 第三段说明为什么 secondary actor 的视角改变了一切

## 反模式

| 反模式 | 问题 | 修正 |
|--------|------|------|
| 共识是伪共识 | "大家都认为X有好处"，但实际上已有文献讨论过负面影响 | 必须在文献综述中诚实承认已有讨论，然后精确定位**特定维度**的盲点 |
| 盲点过于狭窄 | "然而没有研究考察周三的ingratiation" | 盲点必须有理论意义，不能只是时间/地点/样本的微小变化 |
| 视角转换后无理论跟进 | "上级也会受影响" → "所以我们研究上级的压力" | 必须解释为什么 secondary actor 的视角能揭示**新的理论机制** |
