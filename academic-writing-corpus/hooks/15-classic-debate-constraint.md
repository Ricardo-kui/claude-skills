# Classic Debate + Constraint Relaxation Hook

## 功能定义
先呈现一个经典学术辩论（如股东至上 vs 利益相关者），然后引入一个制度变化或方法创新，使得这个辩论可以在新的条件下被重新检验。这种hook将"旧问题"转化为"新机会"。

## 句法模板

**模板 A（制度变化型）**：
```
The debate between [Perspective A] and [Perspective B] is one of the [most enduring / most consequential] in [field].
[Second sentence: core claims of Perspective A].
[Third sentence: core claims of Perspective B].
[Fourth sentence: historically, this debate has been difficult to adjudicate because [empirical or methodological constraint]].
However, [institutional change / methodological innovation / new data source] now makes it possible to [test / compare / relax] [key assumption].
```

**模板 B（方法突破型）**：
```
Scholars have long disagreed about [question].
[Proponents of View A argue...].
[Proponents of View B counter...].
[This stalemate has persisted because [identification problem / data limitation / confounding factor]].
We leverage [new setting / natural experiment / method] to [break the stalemate / provide clean evidence].
```

## 例句（来自 MVP30）

**来源**：How Shareholder Litigation Risk Influences Firm Orientation Toward Stakeholders（来自 memory mapping）

> "The shareholder primacy view holds that... The stakeholder view contends that... What if the constraints on managerial discretion were relaxed?"

**改写模板**：> "The debate between [Perspective A] and [Perspective B] is one of the most enduring in [field]. [Perspective A] holds that [core claim] ([citations]). Conversely, [Perspective B] contends that [core claim] ([citations]). Historically, this debate has been difficult to adjudicate because [constraint]. However, [institutional change / methodological innovation] now makes it possible to [test which perspective dominates under what conditions]."

## 使用场景

| 维度 | 建议 |
|------|------|
| **Outlet 偏好** | ASQ, Organization Science, SMJ — 理论对话型期刊 |
| **理论类型** | **公司治理 / 制度理论 / 战略管理** — 任何存在经典二分法的话题 |
| **前提条件** | 辩论必须真实且持续多年；"约束放松"必须有具体机制（不能是"现在有大数据了"这种泛泛而谈） |
| **风险** | 如果约束放松的论证不成立，整个论文的合法性会崩塌 |

## 关键技巧：约束的精确描述

必须具体说明**什么约束**被放松了：
- 不是"以前没有数据"
- 而是"以前的样本中[某制度安排]使得[某机制]无法被单独识别"
- 新的制度/方法/数据**恰好解决了这个识别问题**

## 反模式

| 反模式 | 问题 | 修正 |
|--------|------|------|
| 辩论是伪辩论 | "有人认为好有人认为坏" — 过于宽泛 | 必须是具体的理论分歧，有 named authors 和 precise predictions |
| 约束放松是幌子 | "现在有了更好的数据" — 任何论文都可以这么说 | 约束必须和辩论的核心识别问题直接相关 |
| 直接选边站 | "我们发现A对B错" | 更好的方式是"我们发现A在X条件下成立，B在Y条件下成立" |
