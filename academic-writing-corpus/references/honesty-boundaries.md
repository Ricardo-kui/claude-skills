# Honesty Boundaries

> 借鉴 Nuwa-Skill 诚实边界原则，明确叙事模板语料库的适用范围和局限。
> **一个不告诉你局限在哪的语料库，不值得信任。**

---

## 一、语料库覆盖范围

### ✅ 覆盖的论文类型

| 维度 | 覆盖范围 |
|------|---------|
| **研究范式** | 量化实证研究（quantitative empirical） |
| **设计类型** | 面板数据回归、自然实验/DiD、工具变量、非线性模型 |
| **期刊** | ASQ, AMJ, SMJ, Organization Science（数据偏重前三者） |
| **学科** | 战略管理、组织理论、部分营销（JM） |
| **理论层次** | 组织层面和企业层面为主；个体/团队层面较少 |
| **论文结构** | 标准 IMRaD 结构（Introduction-Methods-Results-Discussion） |
| **语言** | 英文写作 |

### ❌ 未覆盖的论文类型

| 类型 | 说明 |
|------|------|
| **纯理论/概念性论文** | 不含实证检验的 AMR-type 论文 |
| **质性研究** | 案例研究、扎根理论、民族志、过程理论论文 |
| **元分析** | Meta-analysis、系统综述 |
| **实验研究** | 行为实验、实验室实验、场景实验 |
| **模拟/计算模型** | Agent-based modeling、系统动力学 |
| **纯方法论文** | 心理测量学、方法论创新论文 |
| **非英文写作** | 中文管理学期刊（管理世界、南开管理评论）等 |

## 二、模板适用边界

### 模板能做什么

- 提供**经过验证的叙事结构**（某类 Gap × 某类贡献 × 某期刊 → 推荐的段落功能顺序）
- 提供**句式骨架**（占位符模板，用户填入自己的理论内容和实证发现）
- 提供**避坑指南**（该类型论文最常见的 reviewer 批评和如何避免）
- 提供**期刊适配建议**（同一叙事逻辑在 ASQ vs SMJ 中的不同展开方式）

### 模板不能做什么

- **不能替代理论思考**：模板提供叙事结构，不提供理论内容。如果你的 IV/DV 关系没有机制解释，模板无法补救
- **不能替代实证设计**：模板无法告诉你该用什么模型、怎么处理内生性、样本量够不够
- **不能保证发表**：模板基于已发表论文的共性提取，但每篇论文的审稿路径是独特的
- **不能覆盖创新叙事**：真正突破性的论文可能使用语料库外的全新叙事结构——模板应被视为 baseline 而非 ceiling
- **不能跨语言迁移**：模板为英文写作设计，中文叙事逻辑有显著差异

## 三、样本限制

### MVP30 语料库的样本偏差

| 偏差类型 | 说明 | 影响 |
|---------|------|------|
| **期刊偏差** | 论文主要来自 ASQ/AMJ/SMJ | 对 Organization Science、JAP、JOM 等期刊的覆盖不足 |
| **领域偏差** | 战略管理和组织理论为主 | 对 OB/HR、创业、国际商务的覆盖有限 |
| **时间偏差** | 论文覆盖 2010-2024 | 更早期（2000-2009）的叙事范式未被系统提取 |
| **方法偏差** | 面板数据回归占主导 | 对实验、质性、计算模型的覆盖为 0 |
| **语种偏差** | 全部为英文论文 | 中文管理学期刊的叙事范式完全不同 |
| **选择偏差** | 已发表 = 已通过审稿过滤 | 语料库只看到 "成功的例子"，不知道 "失败的尝试" |

### 当前语料库成熟度

| 指标 | 数值 | 含义 |
|------|------|------|
| 已完成条目 | 17/67（25%） | 大量条目仍是骨架，不可直接调用 |
| 已验证条目 | 0/17（0%） | 所有已完成条目均为单论文观察，未跨论文验证 |
| 训练集论文分析 | ~5/30（17%） | 大部分 MVP30 论文尚未完成深度叙事分析 |
| 跨期刊覆盖 | 2/6（33%） | ASQ 和 SMJ 覆盖较好，AMJ/OS/JM 覆盖薄弱 |

## 四、使用建议

### 对于写作用户

- **优先使用已验证条目**（`✓ VERIFIED` 或 `✓✓ ROBUST`），这些条目经过跨论文验证，可靠性更高
- **谨慎使用实验性条目**（`🔬 EXPERIMENTAL`），这些条目仅基于 1 篇论文，可能过拟合
- **为你的论文做 reality check**：模板说 "这样写好"，但你的论文可能更适合另一种方式——相信你的判断
- **报告意外发现**：如果你用了某个模板但审稿人/同事给了意料之外的反馈，记录为反例

### 对于贡献者

- 每新增一个 corpus 条目，必须标注当前验证状态
- 每发现一个 pattern 的新实例，更新该条目的 "来源论文" 列表
- 发现反例（某期刊某论文故意不遵循此 pattern 且效果更好）→ 记录到反模式 section
