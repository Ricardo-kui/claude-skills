# "Reality Contradicts Consensus" Tension

## 功能定义
当文献已经形成一个看似稳固的共识，但经验现实持续出现与该共识相反的模式时，用现实的"顽固性"来刺破理论的过度自信，迫使读者接受：现有解释框架需要修正或补充。

## 句法模板

**模板 A（共识陈述 + 现实反例）**：
```
[Theoretical consensus]: scholars have [established/agreed/shown] that [prediction] ([citations]).
[Contradictory reality]: Yet [empirical pattern / institutional fact / market behavior] consistently [deviates from / violates / contradicts] this prediction.
[Third sentence: why this contradiction is not just noise].
```

**模板 B（持续存在型）**：
```
The dominant view holds that [theoretical prediction] ([foundational citation]).
However, [phenomenon X] persists [despite / in the face of / even when] [condition that should eliminate it according to theory].
[Third sentence: this persistence suggests that [mechanism] may be [incomplete / conditional / fundamentally different than theorized]].
```

## 例句（来自 MVP30）

**来源**：Two Sides of the Same Coin（来自 memory mapping）

> "Consensus holds that ambiguous classification hurts market participants, yet reality shows that it persists across numerous markets."

**来源**：State Ownership and Firm Innovation

> "One perspective characterizes SOEs as 'dying dinosaurs'... Another portrays them as 'dynamic dynamos'... In 2014, 106 Chinese firms appeared on the Fortune Global 500 list; two-thirds were SOEs."
（此处理论矛盾与现实数据同时并存，是最强形式）

**改写模板**：
> "[Theoretical consensus / Dominant view] holds that [prediction] ([foundational citation]). However, [empirical pattern] consistently [deviates from / violates] this prediction: [specific evidence]. This [persistence / contradiction / anomaly] suggests that [theoretical mechanism] may be [incomplete / oversimplified / contingent on unstated boundary conditions]."

## 使用场景

| 维度 | 建议 |
|------|------|
| **Outlet 偏好** | ASQ, Organization Science, SMJ — 任何欢迎"理论修正"的期刊 |
| **理论类型** | **范式挑战 / 边界条件 / 情境依赖** — 适合修正过度泛化的经典理论 |
| **前提条件** | 共识必须真的有文献支撑（不能是稻草人）；现实反例必须足够系统（不能是轶事） |
| **风险** | 如果 reviewer 认为"现实反例"只是测量误差或选择偏差，tension 会失效 |

## 关键技巧：让"矛盾"看起来不可消除

弱表达："However, some studies find different results."
强表达："However, [phenomenon] persists even in [extreme condition where theory says it should disappear], suggesting that the [theoretical] omission is [structural / fundamental] rather than [peripheral / conditional]."

**关键词**：persist, endure, survive, continue to, despite, even when

## 反模式

| 反模式 | 问题 | 修正 |
|--------|------|------|
| 把反对文献当作"现实" | "Smith (2010) found opposite results" — 这是文献矛盾，不是现实矛盾 | 必须用**制度事实、市场数据、长期趋势**作为反例，而非另一篇论文 |
| 矛盾后无理论出路 | 只说"现有理论有问题"，不说怎么修正 | 必须预告你的修正方案："We argue that this persistence arises because [new mechanism]" |
| 共识是伪共识 | 声称"所有人都认为X"，但实际上已有大量修正文献 | 必须承认修正文献的存在，但指出它们仍未解决核心问题 |

## 变体表达

| 变体 | 强调重点 |
|------|----------|
| "Yet [phenomenon] persists" | 强调持续性 |
| "Despite [condition], [outcome] continues" | 强调条件-结果的张力 |
| "This [pattern] is difficult to reconcile with [theory]" | 强调调和困难 |
| "[Theory] would predict [X], yet we observe [Y]" | 强调预测失败 |
