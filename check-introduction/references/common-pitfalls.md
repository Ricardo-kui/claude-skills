# Common Pitfalls and Post-Revision Checks

Use this reference for the universal禁忌 check and回流 check.

## Universal Pitfalls

- [ ] **Do not borrow hook form only**: Hook must serve the later theoretical tension (Pontikes 2012's consensus establishment serves later overturning)
- [ ] **Do not write empirical preview as result stacking**: Empirical preview should respond to promised mechanism, boundary, or puzzle (Wu 2025)
- [ ] **Do not write contribution paragraphs as literature lists**: Each contribution must explain how the original conversation changes (Han 2024)
- [ ] **Do not cross-journal copy without adaptation**: SMJ's calm opening does not fit ASQ's theoretical debate; ASQ's detailed construct differentiation needs compression in SMJ
- [ ] **Do not use "Interestingly" to introduce findings** (reserved for JM; insufficiently academic for other journals)
- [ ] **Do not push all limitations to future research**: Explain constraints on current interpretation
- [ ] **Symmetric dual-track: do not favor one side**: Group A/B logic must be presented symmetrically; do not assume uniform impact (OS employee_free_speech)
- [ ] **Classic theory disruption: do not lack runway**: Challenging Weber/Bourdieu needs sufficient theoretical argument before empirical preview (ASR Hahl 2017)
- [ ] **2×2 mapping: do not stop at surface**: Each cell needs independent mechanism explanation, not just labels (SMJ Gamache 2020)
- [ ] **Consensus challenge: do not lack concrete counterexamples**: Challenging meta-analytic consensus needs concrete people, companies, and amounts (SMJ Gamache 2023)
- [ ] **Three-reason gap: do not become mere listing**: Each reason must correspond to theory, mechanism, and practice dimensions respectively (JM Malshe 2015)
