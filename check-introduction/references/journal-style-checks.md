# Journal Style Checks

Use this reference when the user specifies a target journal.

## SMJ

| Check item | Standard | Status |
|-----------|----------|--------|
| Calm, professional hook | SMJ prefers calm opening; minimal anecdote / emotional hook (Han 2024 exception with contrast case) | ✓/△/✗ |
| Concise contribution claims | SMJ usually 2-3 contribution paragraphs, no more than 3 | ✓/△/✗ |
| Identification strategy share | Natural-experiment papers allow larger identification-strategy share (e.g., Wu 2025 ~25%) | ✓/△/✗ |
| Literature conversation targeting | Does each contribution precisely target a specific literature? | ✓/△/✗ |
| Consensus challenge anchored | Counterexamples must include specific names, firms, and numbers | ✓/△/✗ |

## ASQ

| Check item | Standard | Status |
|-----------|----------|--------|
| Theoretical depth | ASQ allows more theoretical hooks (interdisciplinary analogy, classic theory establishment) | ✓/△/✗ |
| Construct differentiation | If construct-differentiation type, is distinction sufficient and systematic? | ✓/△/✗ |
| Process model | If qualitative / process theory, are dynamic relationships clear? | ✓/△/✗ |
| Discussion preview | ASQ Discussion usually longer than Introduction; moderate theory-implication preview in Intro is acceptable | ✓/△/✗ |

## AMJ

| Check item | Standard | Status |
|-----------|----------|--------|
| Managerial relevance | Is relevance to management practice established? | ✓/△/✗ |
| Multi-level implications | Does it demonstrate micro-macro bridging potential? | ✓/△/✗ |
| Boundary conditions | Is boundary-condition discussion deep enough? | ✓/△/✗ |

## OS

| Check item | Standard | Status |
|-----------|----------|--------|
| Policy / practice tension | Does it translate practice tension into theoretical puzzle? | ✓/△/✗ |
| Symmetric dual-track balance | Same policy's logic for Group A and Group B presented symmetrically? | ✓/△/✗ |
| Counterintuitive implications | Does it emphasize institutional implications of counterintuitive findings? | ✓/△/✗ |
| Values dimension | Is political / values dimension ignored when it is central to the phenomenon? | ✓/△/✗ |

## ASR

| Check item | Standard | Status |
|-----------|----------|--------|
| Classic theory depth | Is there explicit dialogue with Weber / Bourdieu or other canonical literature? | ✓/△/✗ |
| Theoretical runway | Does theory argument dominate; is empirical preview sufficiently前置? | ✓/△/✗ |
| Theory replacement | Does it propose a new mechanism替代旧解释, rather than only gap-filling? | ✓/△/✗ |
| Experiment positioning | Are experiments positioned as theory-testing tools, not main contribution? | ✓/△/✗ |

## JM / JMR / MSOM / IJRM

| Check item | Standard | Status |
|-----------|----------|--------|
| Consumer / operations orientation | Are practical implications focused on specific domains (consumer welfare, operational efficiency, marketing management)? | ✓/△/✗ |
| Economic significance | Is economic significance previewed? | ✓/△/✗ |
| Cross-disciplinary anchoring | When borrowing from other disciplines, is sufficient bridge established? | ✓/△/✗ |
