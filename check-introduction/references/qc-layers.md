# QC Layers — Six-Layer Introduction Check

Use this reference when executing the six-layer QC check.

## Layer 1: Hook × Gap Strength Matching

| Check item | Standard | Status |
|-----------|----------|--------|
| Hook strength matches gap strength | Incompleteness should not use strong hook; Incommensurability should not use mild hook | ✓/△/✗ |
| Hook introduces knot | Does paragraph 1 establish tension that makes readers continue? | ✓/△/✗ |
| Hook is directly research-relevant | Or is it just an "interesting anecdote"? | ✓/△/✗ |

## Layer 2: Conversation × Gap Type Matching

| Check item | Standard | Status |
|-----------|----------|--------|
| Conversation strategy matches gap type | Incompleteness→Progressive; Inadequacy→Synthesized/Non-Coherence; Incommensurability→Non-Coherence | ✓/△/✗ |
| Literature review builds conversation | Or is it just a literature list? | ✓/△/✗ |
| Transition is clear | From "what we know" to "what we don't know" — is it natural? | ✓/△/✗ |

## Layer 3: Problematization Depth

| Check item | Standard | Status |
|-----------|----------|--------|
| Incompleteness: explains theoretical importance of omission? | Not just "few studies have examined" | ✓/△/✗ |
| Inadequacy: provides specific literature evidence? | Not vaguely "researchers have overlooked" | ✓/△/✗ |
| Incommensurability: challenge anchored in evidence? | Not erecting straw men | ✓/△/✗ |
| Problematization transcends pure gap-spotting? | Does it rise to a theory-level problem? | ✓/△/✗ |

## Layer 4: Makadok Statement + Paragraph Completeness

| Check item | Standard | Status |
|-----------|----------|--------|
| Makadok dimension statement visible? | Does What We Learn paragraph clearly declare which lever changes? | ✓/△/✗ |
| Can Discussion deliver the claim? | Claim and delivery one-to-one match? | ✓/△/✗ |
| Paragraph functions complete? | Hook→Conversation→Problematization→So What→What We Learn | ✓/△/✗ |
| Protagonist clear? | Core IV/DV appear in first two paragraphs? | ✓/△/✗ |

## Layer 6: Exemplar Comparison

| Check item | Standard | Status |
|-----------|----------|--------|
| Paragraph length distribution | Matches closest exemplar? (e.g., SMJ gap paragraph shortest, identification-strategy longest; ASR theory-argument longest) | ✓/△/✗ |
| Hook type consistency | If targeting SMJ but uses Epigraph Hook, verify journal fit; ASR without classic-theory dialogue is a warning | ✓/△/✗ |
| Problematization strength | Does exemplar use "has gone largely unaddressed" (Incompleteness) or "failed to distinguish" (Inadequacy) or "shattered this image" (classic theory disruption)? | ✓/△/✗ |
| Architecture type consistency | Three-reason gap (JM) / symmetric dual-track (OS) / consensus challenge+counterexample (SMJ) / classic theory disruption (ASR) — does structure match exemplar? | ✓/△/✗ |
| Contribution statement count | How many contribution paragraphs does exemplar have? Does user have too many / too few? | ✓/△/✗ |
