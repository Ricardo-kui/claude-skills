# Writeup Matrix

## Artifact To Skill

- regression or balance table -> `latex-tables`
- event-study or coefficient figure -> `econ-visualization`
- methods or results subsection -> `write-methods-and-results`
- discussion or implications -> `write-discussion-and-conclusion`
- script-to-table reconciliation -> `review-code`

## Claim-Strength Rules

- descriptive design -> describe patterns only
- associative design -> use association language
- strong causal design with diagnostics -> causal language allowed, but still note scope limits

## Minimum Evidence Map

- claim
- evidence source
- model or figure id
- practical interpretation
- caveat
