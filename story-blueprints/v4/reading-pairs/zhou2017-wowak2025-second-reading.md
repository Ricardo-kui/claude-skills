# 三篇对照阅读：Zhou (2017) × Wowak et al. (2025) × Ridge et al. (2013)

## 结论

这不是三篇同型“理论对垒”论文的并列范本。三篇都出现相反预测或混合发现，但**张力来源、理论动作与结局资格不同**：

| 判断问题 | Zhou (2017) | Wowak et al. (2025) |
| --- | --- | --- |
| 张力从何而来？ | 已有的效率逻辑、制度逻辑、现实反例和混合证据共同构成同一关系的真实冲突。 | 两个文献在新交叉点留下空白；相反预测主要由作者为每个结果过程构造。 |
| 两条理论线在回答什么？ | 同一创新过程中的资源获取与资源利用。 | 不同时间点的产品安全过程：预防质量失败与发现失败后的召回响应。 |
| 合法的解结动作 | 让两条逻辑分别解释一个可观察 facet，并导出二者均不能单独导出的整合预测。 | 让不同机制在不同结果过程上分别成立；不能把它误写成同一因果链上的理论整合。 |
| 结尾是否由前端长出？ | 基本长出：回到“哪种逻辑对”，解释为何双方各解释一部分。 | 部分长出：双结果答案兑现，但政治多样性处方在 post hoc 才取得重要地位。 |

| 判断问题 | Ridge et al. (2013) |
| --- | --- |
| 张力从何而来？ | 社会比较与 tournament 理论及其经验结果对同一 pay-disparity–performance 关系给出相反预期。 |
| 两条理论线在回答什么？ | 同一个 X→Y 关系，但各理论只在不同 pay-disparity 区间内具备自身的前提。 |
| 合法的解结动作 | 回到 similarity 与 prize-size 两项原始前提，说明 X 的程度改变了哪一机制适用；由此推出 U 型。 |
| 结尾是否由前端长出？ | 基本长出：heir apparent、CEO power 与 eligibility 作为机制检验，回到“互补而非对立”。 |

## 适用判别

### Zhou 式 facet integration 仅在以下条件同时成立时可学习

1. 两个解释对同一焦点关系都已有真实理论与/或实证立足点；
2. 它们实际描述同一因果过程内可区分的机制或阶段，而非两个不同结果；
3. 研究能观察或检验这些 facet，并导出一个任何单一逻辑都不能给出的联合预测；
4. 非线性、折中或“中间最优”结论由机制结构推出，而不是为调和结果而选择。

### Wowak 式 dimension split 仅在以下条件同时成立时可学习

1. 两个结果具有独立的理论含义，不是同一构念的替代测量；
2. 它们对应不同的决策时点、行动过程或利益相关者后果；
3. 每个结果有独立机制链，且两者仍共同回答一个更高阶问题；
4. 任何“兼得”或缓解处方在前端已有理论准备，或被明确限定为 post hoc。

### Ridge 式 theory-domain shift 仅在以下条件同时成立时可学习

1. 两个解释对同一 X→Y 关系存在真实理论或实证冲突；
2. 每个理论都含有可辨识的适用前提，且 X 的程度能够改变该前提是否成立；
3. 理论转折能导出明确的区间性或非线性预测，而不是事后拟合曲线；
4. 额外分析能检验“为何在该区间转折”的机制，而非仅重复报告平方项。

## 对写作调用的收紧规则

- 当请求说明的是“同一关系的理论—证据冲突”，才允许 Zhou 作为 Introduction / Theory 学习对象。
- 当请求明确说明两个结果过程为何不同、却共同回答同一问题，才允许 Wowak 的 Theory 或 Results 建议出现。
- 当请求已证明 X 的程度会改变理论本身的适用前提时，才允许 Ridge 作为 Introduction / Theory 学习对象。
- 只有“有两个因变量”“文献结论不一致”或“希望写出反直觉结论”时，三者均不得被推荐为结构范本。
- Wowak 的 Introduction 保持 `partial`，Theory 从 `yes` 收紧为 `partial`；它的主要检索价值是对照与 Results 的双重揭示。

## 未作出的判断

本记录只比较叙事组织，不评价所涉论文的因果识别、理论正确性或发表价值。

## 边界对照：Zhong et al. (2020) 不属于上述三种解结

Zhong 2020 表面上也有多个理论视角、一个中介和一对相反方向的结果（search depth / breadth），但它不是 Zhou 式 facet integration、Wowak 式 dimension split，也不是 Ridge 式 theory-domain shift。Capability 与 cognition 研究在文中并不对同一关系提出相反预测；它们共同留下了需求侧如何进入注意力与搜索的机制空白。该文的正确学习动作是 **cross-domain mechanism bridge**：customer concentration → existing-oriented executive attention → deeper and narrower search。

因此，调用端只有在当前研究已确认“两个相容但分离的文献留下一个可检验的机制连接”时，才可推荐 Zhong；不能因研究具有多个理论、两个因变量或中介模型而推荐它。

## 新增边界对照：Post, Lokshin, and Boone (2022) 是“并行路径的机制悖论化解”

Post et al. 的两条机制线也通向一对结果（R&D 与 M&A），但它既不是 Zhong 的同一注意力机制的成对后果，也不是 Wowak 让不同机制在不同结果过程上各自胜出的 dimension split。该文从一个前置的机制悖论出发：女性进入高层团队被认为会同时提高 change orientation、降低 risk-taking propensity；若把战略变化理解为单一路径，这两种变化看似相反。作者把 strategic renewal 划分为 capability building（R&D）和 capability buying（M&A），从而显示两条认知变化各自改变不同路径，却共同把更高阶的更新轨迹从 buying 推向 building。

因此，Post 卡只在本次写作调用已确认以下三点时才可出现：

1. 文献或现象中确有一个不能靠“加一个中介”消除的机制层悖论；
2. 两条路径的下游行动过程不同，且不是同一构念的重复测量；
3. 两条路径都有理论基础共同指向一个可清楚命名的高阶变化。

若只有多个中介、两个因变量、或“相反系数”，均不足以调用 Post。此时应先判断它究竟是 Zhong 式单一机制的成对后果、Wowak 式不同结果过程，还是没有可学习的故事解结。
