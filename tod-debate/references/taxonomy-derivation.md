# Taxonomy Derivation — 维度派生协议、主张分类学、双门禁与判定校准层

本文件是四样东西的唯一权威：辩论维度怎么从知识库派生、新颖性主张怎么分类、两道扩展门禁的定义、叶子判定与 margin 的管理学校准标准。

校准来源（转译使用——这些源的写作场景是评估单篇稿件，对辩场景下做定位器/子题源/判定语义，不照搬其清单格式）：Pollock (2025) Ch13 表13.1（拒稿 vs 修改的 11 维标准）与建设性评审节；AMJ Management Research Canvas（九要素编辑问句）；战略管理理论贡献八杠杆指南；Edmans (2023)（先验更新语义）；JIBS desk-reject editorial。

## 一、辩论维度派生协议

每场对辩开辩前派生本场维度表（Step 0 执行）。派生优先、静态兜底；派生来源路径必须记录在案。

| 稿件类型 | 派生来源（按序读取） | 映射 |
|---|---|---|
| 召回研究 | `D:\Onedrive\Obsidian Vault\产品召回\03 前因与驱动`、`05 概念`、`02 影响后果`、`02 主题` | 每个现有主题/概念分类 → 一个候选辩论维度；clock-start、召回发起方、机制家族通常已在概念库中成形 |
| 政策 DiD 稿 | `论证卡库\03 Method Cards` + `概念库\01 概念` + 相关专题库（`共同所有权\`、`竞业协议\`） | Method Cards → 识别维度（冲击定义、估计家族、平行趋势证据）；概念库 → 构念维度 |
| 其他实证稿 | `概念库` + 相关 MOC（`literature\` 内的 MOC 文件） | 主构念与理论对话 → 维度 |

派生规则：
- 维度数 5–8 个；每个维度一句话定义 + 判别问题（"两文在此维度上的贡献主张是否分叉？"）
- 专题库的分类语言优先于通用术语——辩论维度说作者库里的语言（构念先于操作化在分类学层生效）
- 派生来源为空或与稿型不匹配 → 用下节静态兜底表

### 静态兜底表

**政策 DiD 稿型**：政策冲击定义与变异来源 / 识别策略家族（DiD、事件研究、IV）与平行趋势证据 / 结果构念操作化 / 机制证据（中介、异质性、安慰剂）/ 理论框架与对话文献 / 样本、行业与时期、外部效度。

**召回研究稿型**：clock-start 定义（investigation- vs awareness-to-recall）/ 召回发起方（firm-initiated vs regulator-forced）/ 时距模型选择（hazard vs 线性）与设定 / 机制家族（learning、deterrence、stigma）/ 行动者层级（CEO、团队、组织）/ 行业、产品类别与监管制度背景。

## 二、新颖性主张分类学（persona 生成主张的唯一分类）

管理学实证论文的新颖性主张只有六类：

| 标签 | 含义 | 判别问题 |
|---|---|---|
| `construct-operationalization` | 新构念的引入或已有构念的新操作化 | 换掉这个测量，主张还成立吗？ |
| `identification-variation` | 新的识别变异来源（新冲击、新制度断点、新匹配结构） | 这个变异是论文自己构造的，还是文献已用过的？ |
| `mechanism-evidence` | 新机制证据（中介、调节、falsification 图形） | 机制主张有没有区分性证据，还是只有主效应？ |
| `boundary-condition` | 新边界条件（scope、情境、异质性） | 边界是理论推出的还是切片切出来的？ |
| `setting-data` | 新情境或新数据 | 新情境改变关系本身，还是只换了背景板？ |
| `theoretical-reframing` | 理论重构（同一现象换了对话） | 新对话被证据兑现了吗，还是只换了引用列表？ |

**执行细节清单（单独不构成主张）**：估计量选择（TWFE 修正、CS-D、SA、stacked）、聚类层级、显著性水平、样本量、数据清洗步骤。执行细节可以支撑主张（"新变异让我们能识别"成立），persona 陈述中允许出现，但 moderator 的子题生成与叶子判定只认六类主张。

## 三、双门禁（moderator 扩展裁决的唯一依据）

**估计量门禁（estimator gate）**：辩论在子题上的剩余分歧若只关于执行选择（估计器家族、聚类、抽样），路径终止。判别：把分歧句中的估计量术语换成"合适的现代方法"后，分歧是否消失——消失即执行之争。

**等价门禁（equivalence gate）**：两文在同一子题上共享政策冲击 + 同族结果变量 + 同设计家族时，路径必须以显式的 equivalent 或 incremental 判定终止，含糊的"有所不同"不算判定。这是审稿人 convex combination 攻击的实锤检验——incremental 判定必须写明 margin（增量是什么、多大、凭哪段证据）。

## 四、判定语义（叶子判定的唯一权威）

- **unique**：此子贡献只在一方面成立，对方无对应主张或对方对应主张证据不足
- **incremental**：对方先立此贡献，本文以可写明的 margin 扩展之（margin 一句话 + 证据）
- **equivalent**：两文的此子贡献在构念与证据层面相同，措辞差异不构成区分
- 判定对象永远是**主张对**（claim-pair），不是论文整体；论文级结论由定位表汇总得出，作者拍板

## 五、判定校准层（叶子判定与 margin 的管理学标准）

判定的证据接地靠辩论记录，判定的**语义边界**靠以下三条校准。执行顺序：先过双门禁（第三节），再按本节定位 margin、细化判定语义。

### 5.1 八杠杆 → margin 定位器

incremental 判定的 margin 必须能落到八根理论杠杆之一（research question / mode of theorizing / level of analysis / phenomenon / causal mechanism / constructs / boundary conditions / theory outputs），并通过该杠杆的 Writing Diagnostic 问句。两用途：

- **margin 真实性仲裁**：persona 声称的区分若说不出落在哪根杠杆、或过不了该杠杆诊断问句（"构念做了理论工作还是只重命名了测度？""现象有理论诊断力还是只是有趣？""边界条件提升了预测精度还是没有？"），margin 记为 **rhetorical**——定位表行标注之，不作为防御依据
- **对比双方的杠杆账本**：A 换了 phenomenon、B 引入了 construct 时，判定不是谁更强，而是两笔不同的理论变动——这直接支撑 distinct；同一杠杆上的不同程度改动才是 incremental 的自然栖息地

同时按杠杆风险四项自查存活主张：contribution too generic（不可定位到杠杆）/ phenomenon without theory / construct relabeling without mechanism / boundary condition without precision gain。命中者其主张降格处理并在判定理由中注明。

### 5.2 表13.1 → equivalent/distinct 语义细则

等价门禁的结构同质判据之上，加两条对话层判据：

- **对话可识别性**（表13.1 第二行）：两部论文加入的对话可以清楚区分吗？不同对话或不同受众 → 即使结果相近也倾向 distinct；同一对话、回答同一子问题 → equivalent 倾向
- **理论贡献潜力互斥性**（表13.1 第一行）：一部论文的贡献是否构成另一部贡献的直接增量？是 → incremental（margin = 那道增量）；各自独立成立、互不为增量 → distinct；互换措辞后读者先验无差别 → equivalent

自明/同义反复假设检查（表13.1 假设陈述行）同样适用于对辩：任何一方的主张若无法构造反事实（"什么结果会推翻它"），该主张不计入定位表。

### 5.3 Canvas 替换检验 → 子题备用源

moderator 子题生成除稿件结构分类学（第一、二节）外，可从 AMJ Canvas 九要素问句派生新颖性子题，高频三问：

- **替换检验**（abstract 要素）：把 A 稿的关键构念代入 B 稿摘要仍通顺吗？通顺 → 两稿可能共享同一理论位置（强烈提示 equivalence probe 子题）
- **反事实清晰度**（design 要素）：两部论文的反事实各是什么？可比 → 反事实差异本身可成一个区分性子题；一方语焉不详 → 该方在 identification 主张上的立论打折（moderator 记录，供 positioning 行使用）
- **直觉答案强度**（RQ 要素）："How would reasonably informed people intuitively answer this question?"——直觉答案强且两部论文答案相同 → 该主题的新颖性存疑，moderator 可用此问压双方的 novelty 主张

### 5.4 Ch12 元规则（选择性吸收；作者侧指导仅取 moderator 层）

Pollock Ch12 是作者应对审稿人的指导，**整章不进 persona**——作者 persona 若有"驳回批评"的元工具会破坏对抗平衡（persona 的职责是诚实立论）。只取两条 moderator 层规则：

- **特质意见降权**：合并总表场景下，只有单场辩论单一节点以 weak 证据支持的判定，在报告中等价于 idiosyncratic comment——标注降权，提醒作者这是单人审稿人视角的弱信号
- **定位弱信号**："审稿人建议完全不同的故事，说明你没把自己的故事讲好" → persona 在某节点只能攻击对方而讲不出自己的正贡献地图时，moderator 在该节点记对方 positioning-strong / 本方 positioning-weak，写入对应行的含义列
