# Glossary — Wooldridge, Introductory Econometrics (8th ed.)

**2SLS (two stage least squares)** — IV estimator using first-stage fitted values as the instrument; the single-best-IV combination of multiple instruments (Ch 15, 16)
**Adjusted R-squared** — R² penalized for regressors; use for nonnested model comparison, never as a causal criterion (Ch 6)
**APE (average partial effect)** — partial effect averaged over the covariate distribution; the right scale for reporting logit/probit/Tobit effects (Ch 6, 17)
**AR(1) serial correlation** — error follows u_t = ρu_{t−1} + e_t; invalidates usual time-series SEs (Ch 11, 12)
**Attenuation bias** — CEV measurement error in a regressor biases its coefficient toward zero (Ch 9)
**ATE / ATT** — average treatment effect / ATE on the treated; potential-outcomes estimands (Ch 2, 19)
**Bad control** — a variable that is itself an outcome of treatment or a mediator; controlling for it blocks the causal path (Ch 3, 6)
**Breusch-Godfrey test** — LM test for AR(q) serial correlation valid with lagged dependent variables (Ch 12)
**Breusch-Pagan test** — regress û² on the regressors to test homoskedasticity (Ch 8)
**Ceteris paribus** — holding all else fixed; the causal thought experiment behind every structural coefficient (Ch 1)
**CEV (classical errors-in-variables)** — measurement error uncorrelated with the true regressor; causes attenuation (Ch 9)
**Chow test** — F test for equality of entire regression functions across groups (Ch 7)
**Cluster-robust SE** — variance estimator allowing arbitrary within-cluster correlation; mandatory for panel and clustered policy data (Ch 13, 14)
**Cochrane-Orcutt / Prais-Winsten** — FGLS for AR(1) errors via quasi-differencing; PW keeps the first observation (Ch 12)
**Cointegration** — I(1) series with a stationary linear combination; validates levels regression via ECM (Ch 18)
**Control function** — include first-stage residuals to test/correct endogeneity (Ch 15, 19)
**Correlated random effects (Mundlak)** — add unit time-averages to RE; reproduces FE and tests RE vs FE (Ch 14)
**Critical value / p-value** — rejection threshold vs. smallest significance level at which H₀ is rejected (Ch 4)
**DiD (difference-in-differences)** — before/after × treated/control contrast; identifies under parallel trends (Ch 13, 19)
**Dickey-Fuller test** — unit-root test on Δy with non-standard critical values (Ch 18)
**Dummy variable trap** — including g dummies plus intercept for g groups ⇒ perfect collinearity (Ch 7)
**Dynamically complete model** — no serial correlation once enough lags included; E(y_t|x_t, past) = E(y_t|x_t) (Ch 11)
**ECM (error correction model)** — Δy_t responds to lagged disequilibrium from a cointegrating relation (Ch 18)
**Endogeneity** — any correlation between regressor and error: omitted variables, simultaneity, measurement error (Ch 3, 15, 16)
**Exogeneity hierarchy** — strict ⊃ sequential ⊃ contemporaneous; determines which properties survive (Ch 10, 11)
**FGLS** — GLS with estimated variance/correlation structure; consistent, more efficient, not unbiased (Ch 8, 12)
**First-difference (FD) estimator** — difference away the unit effect a_i with T=2 or more (Ch 13, 14)
**First stage** — regression of endogenous regressor on instruments; F>10 relevance rule (Ch 15)
**Fixed effects (within) estimator** — time-demeaning removes a_i; kills all time-constant regressors (Ch 14)
**Frisch-Waugh(-Lovell)** — partialling out: a multiple-regression slope equals the simple regression on residualized x (Ch 3)
**Gauss-Markov assumptions (MLR.1–5)** — linearity, random sampling, no perfect collinearity, zero conditional mean, homoskedasticity ⇒ OLS is BLUE (Ch 3)
**HAC / Newey-West SE** — heteroskedasticity- and autocorrelation-consistent SEs for time series (Ch 12)
**Heckit** — two-step sample-selection correction using the inverse Mills ratio (Ch 17)
**Heteroskedasticity** — Var(u|x) varies with x; leaves OLS unbiased but breaks usual SEs (Ch 8)
**I(0) / I(1)** — stationary vs. integrated (unit-root) series; ρ̂ > 0.9 ⇒ difference (Ch 11, 18)
**Incidental truncation / sample selection** — y observed only when another variable crosses a threshold (Ch 17)
**Instrument relevance / exogeneity** — Cov(z,x)≠0 (testable) and Cov(z,u)=0 (not testable) (Ch 15)
**Inverse Mills ratio** — λ(zγ) = φ/Φ; the Heckit correction term (Ch 17)
**IPW / doubly robust (IPWRA)** — propensity-score weighting; IPWRA consistent if either the mean or the propensity model is right (Ch 19)
**Joint significance (F test)** — test q exclusion restrictions via SSR or R² forms (Ch 4)
**LATE** — local average treatment effect: IV estimates the effect on compliers (Ch 19)
**LM (score) test** — nR² from the restricted-model auxiliary regression (Ch 5, 8, 12)
**Logit / probit** — binary-response MLE models; report APEs, not raw coefficients (Ch 17)
**LPM (linear probability model)** — OLS on a binary outcome; inherently heteroskedastic, use robust SEs (Ch 7, 8)
**LRP (long-run propensity)** — cumulative effect of a permanent change in an FDL model (Ch 10)
**Measurement error** — in y: costs precision only; in x: attenuation (CEV) (Ch 9)
**Multicollinearity** — high but imperfect regressor correlation; inflates SEs, biases nothing (Ch 3, 4)
**Omitted variable bias** — Bias(β̃₁) = β₂δ̃₁; sign from the Table 3.2 matrix (Ch 3, 5)
**Overlap / common support** — 0 < P(w=1|x) < 1 needed for ATE estimation; trim p̂ outside [0.1, 0.9] (Ch 19)
**Panel data** — same units over time; enables FE/FD removal of time-constant unobservables (Ch 1, 13, 14)
**Parallel trends** — DiD identifying assumption: untreated path = treated counterfactual path (Ch 13)
**Poisson QMLE** — exponential-mean estimator for counts/corners; consistent from the mean alone, use robust SEs (Ch 17)
**Potential outcomes** — y(0), y(1) framework; causal effects as contrasts (Ch 2, 19)
**Propensity score** — P(w=1|x); balancing score for matching/weighting (Ch 19)
**Proxy variable** — observable correlate of an omitted factor; plug-in solution to OVB (Ch 9)
**Quasi-differencing** — transform y_t − ρy_{t−1} to remove AR(1) errors (Ch 12)
**R-squared** — fraction of y-variance explained; never evidence of causality (Ch 2, 3)
**Random assignment** — treatment independent of potential outcomes; delivers unbiased ATE (Ch 2, 19)
**Random effects (RE)** — GLS assuming Cov(x, a_i)=0; efficient if true, inconsistent if not (Ch 14)
**Random walk / unit root** — I(1) process; shocks permanent; regression on levels can be spurious (Ch 11)
**RDD (regression discontinuity)** — treatment jumps at a running-variable cutoff; local linear with IK bandwidth (Ch 19)
**RESET** — add ŷ², ŷ³ and F-test; checks conditional-mean functional form (Ch 9)
**Robust (White) SE** — variance estimator valid under unknown heteroskedasticity (Ch 8)
**Selection bias** — E(y₀|w=1) − E(y₀|w=0) contaminating naive treated-control contrasts (Ch 19)
**Simultaneity** — y and x determined jointly; OLS on one equation is biased (Ch 16)
**Spurious regression** — significant relation between independent trending/unit-root series (Ch 10, 11, 18)
**Stationarity (weak)** — constant mean/variance and time-invariant covariances (Ch 11)
**Stock-Yogo rule** — first-stage |t| > 3.2 (one endogenous regressor) or F > 10 against weak instruments (Ch 15)
**Strict exogeneity** — x uncorrelated with u in all periods; required by FE/FGLS; fails with lagged DV (Ch 10, 14)
**Tobit** — censored-outcome MLE; partial effects scaled by Φ(xβ/σ) (Ch 17)
**TWFE** — two-way fixed effects (unit + time dummies) (Ch 14)
**Unconfoundedness (ATE.1)** — treatment independent of potential outcomes given x (Ch 19)
**Weak instruments** — small first-stage correlation ⇒ biased 2SLS with wrong-sized tests (Ch 15)
**WLS** — weight by 1/h(x) when Var(u|x) = σ²h(x); BLUE under correct weights (Ch 8)
**Zero conditional mean (SLR.4/MLR.4)** — E(u|x)=0; the core identifying assumption of regression (Ch 2, 3)
