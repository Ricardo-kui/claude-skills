# Central Knot 贯穿检查

在输出骨架后执行的全局检查，确保 central knot 被所有段落共同服务。

## 检查清单

- [ ] 每个段落是否提及 central knot 或暗示其存在？
- [ ] Contribution 段是否明确承诺"我们将解开 [knot 简化版]"？
- [ ] 如果去掉某段落，knot 是否仍然完整？不可替代的段落是 knot 的关键支撑

## 段落- knot 对齐表

| 段落 | 与 knot 的关系 | 检查问题 |
|------|--------------|---------|
| P1 Hook | 暗示 knot | 读者能否从 Hook 中感受到核心张力？ |
| P2 Lit Turn | 让 knot 显现 | 已有理解的局限性是否指向这个 knot？ |
| P3 Gap | 精确 tying the knot | 这个 gap 是否就是这个 knot 的具体化？ |
| P4 Stakes | 加深 knot 紧迫性 | 不解决这个 knot 的代价是什么？ |
| P5-P6 Theory Lens | 提出解开 knot 的路径 | 理论是否直接回应这个 knot？ |
| P7-P8 Contribution | 承诺解开 knot | 贡献是否回到 knot 并承诺 resolution？ |

## 不可替代性测试

对每个段落问："如果删掉这一段，central knot 是否仍然完整？"

- 是 → 该段落可能是 extraneous，建议删除或移至附录
- 否 → 该段落是 knot 的关键支撑，保留

## 常见断裂模式

| 断裂模式 | 表现 | 修复 |
|---------|------|------|
| **Gap 偏离 knot** | Gap 指出的问题与 Hook 暗示的张力不是同一个 | 重写 Gap，使其直接回应 Hook 中的 knot |
| **Theory Lens 回避 knot** | 理论透镜没有回应 central knot，而是讨论了一个相关但不同的问题 | 调整理论选择，确保理论直接解释 knot 中的张力 |
| **Contribution 不兑现** | Contribution 声称的贡献与 knot 无关 | 重写 Contribution，明确承诺"我们将解开 [knot]" |
| **Stakes 泛泛** | Stakes 没有具体说明不解决这个 knot 的代价 | 将 stakes 与 knot 绑定："如果不理解 [knot]，则..." |
