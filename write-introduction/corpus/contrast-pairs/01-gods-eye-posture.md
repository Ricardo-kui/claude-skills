# CP-01 — 上帝视角（定义式断言 + 事实语气）

> 失败类型：上帝视角 · 适用模块：Preview / 结果句 / 边界句 · 与 G3 行「不写因果」对应。

## 失败句（逐字 + 出处文件:行）

> "Annual serious recall counts are therefore governance outcomes. They show how the actors around a firm shape the occurrence of consequential defects and the willingness to make detected problems public."

出处：`Introduction_0913_polished.md:24` / `Introduction_0913_vault_current.md:24` / `Introduction_0913_deepened.md:26`

同类实例（同一失败类型的变体）：

> "making annual serious recall counts a portfolio-level governance outcome"

出处：`Introduction_0913_corpus.md:38`（短式）；扩写为 `making the annual number of unique Class I and Class II recall numbers a portfolio-level governance outcome` 的版本见 `Introduction_0913_polished.md:34` / `Introduction_0913_posture.md:37` / `Introduction_0913_deepened.md:36`

## 底本句（引 `_skeleton/` id）

- `mechanism-preview#20`（ridge2013，`corpus/_skeleton/previews.md`，状态 verbatim）：把补充证据写成对机制的支持与替代解释，而非把观察当机制证据。
- 机制语气动词表另见 `references/generation-protocol.md` G4「机制语气库」（`may reflect` / `is consistent with` / `can change` / `we theorize`）。

## 差异字段

| 字段 | 失败写法 | 底本方向 |
|---|---|---|
| 姿态 | 定义式断言 `are therefore` + 事实语气 `They show`：把未观察的治理机制写成定义式并当作已证 | 机制语气 `may reflect` / `is consistent with`：观察与机制相容，不宣称确认 |
| 预算 | 无防御计数问题 | 无 |
| 元语言 | 无 | 无 |
| 具体性 | 落到一般「治理结果」，未点 actor topology 与决策边际 | 点到具体机制通道（谁的损失进入治理计算、哪个边际被改变） |

## 何时会再犯

- 写「X 是 Y」式结果/预览句时，用 `is/are` + `show/demonstrate/reflect` 把机制直断。
- 用「portfolio-level governance condition/outcome」作为唯一构念表达，不落到具体 actor topology。
- 对照改写（G4 回归 case）：`Annual serious recall counts may reflect how governance structures shape which known defects are converted into public action. These counts are consistent with a governance-channel account…`

## 并入的「禁止复活失败写法」（原叙事型句库块）

- 未观察机制写成 `is / shows / demonstrates`。
- "portfolio-level governance condition" 作为唯一构念表达，不落到具体 actor topology。
