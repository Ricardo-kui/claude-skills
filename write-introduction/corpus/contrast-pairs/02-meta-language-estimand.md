## 差异字段

| 字段 | 失败写法 | 底本方向 |
|---|---|---|
| 姿态 | 用「sign」把关系方向本身抬为论题 | 把方向降为结果，把机制抬为贡献 |
| 预算 | 无 | 无 |
| 元语言 | `estimand`（方法语境外的项目管理式元句） | 论文语言：association / mechanism / contribution |
| 具体性 | 抽象到「符号」，不说是哪条机制 | 指明贡献落在哪条机制链 |

## 何时会再犯

- 写 thesis 收尾句、想「明确哪个是贡献」时，用方法词（`estimand` / `adjudication` / `locked`）给贡献定位。
- 目标期刊画像「元句容受」列未标注为允许时，一律按默认转为论文语言。
