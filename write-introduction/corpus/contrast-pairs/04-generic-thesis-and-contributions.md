# CP-04 — 通用句（thesis 占位 + 贡献列举）

> 失败类型：通用句 · 适用模块：Theory Thesis / Contribution 首句 · 无对应 G3 锁定约束行，属表达质量线（`water-level-gate.md` §五 specificity）。

## 失败句（逐字 + 出处文件:行）

> "Our central thesis is that…"

出处：`Introduction_0913_polished.md:28` / `Introduction_0913_deepened.md:30` / `Introduction_0913_posture.md:31`

> "We make two contributions."

出处：`Introduction_0913_polished.md:34` / `Introduction_0913_deepened.md:36` / `Introduction_0913_posture.md:37`

## 底本句（引 `_skeleton/` id）

- `three-layer-contribution#3`（`hoffmann_cheong_phan_zurbruegg2024`，`corpus/_skeleton/contributions.md`，状态 verbatim）：用「问题从后果转向前因」的方式定位贡献，而不是先宣布「有几个贡献」。
- `thesis-models#T4`（`corpus/_skeleton/micro-templates.md`，状态 模板）：`Although we build on [prior framework]'s insight that [A] and [B]…, we [extend / refine / limit] it by [C…]`——thesis 句法权力分配。
- 反例登记：`contributions-index#6`（`corpus/_skeleton/contributions.md`）本身是 "Our paper makes two contributions. First…" 版 verbatim——**它是底本，同时演示了通用列举的风险**，使用时应按 `three-layer-contribution#3` 的问题转换式改写。

## 差异字段

| 字段 | 失败写法 | 底本方向 |
|---|---|---|
| 姿态 | 第一人称占位（`Our central thesis is that…`）先亮相，不携带理论关系 | 用 `Although…we…` / 问题转换承载立场 |
| 预算 | 无 | 无 |
| 元语言 | 无 | 无 |
| 具体性 | 零信息：`central thesis` / `two contributions` 可原样放进任意论文 | 点明被转换的问题（capacity → objective）与最小机制链 |

## 何时会再犯

- 写第一句 thesis 时用 `Our central thesis is that…` 开场。
- 写贡献段时先写 `We make two contributions.` 再补内容（贡献数量本身不是贡献内容）。

## 并入的「禁止复活失败写法」（原叙事型句库块）

- "Our central thesis is that..."
- "We make two contributions."
