## 差异字段

| 字段 | 失败写法 | 底本方向 |
|---|---|---|
| 姿态 | 用「裁决」口吻给补充分析下判定，隐含法庭/项目治理框架 | 写成「补充证据」：相容性陈述，不宣称裁决 |
| 预算 | 无 | 无 |
| 元语言 | `adjudication`（管理/项目管理语言，非论文语言） | 论文语言：supplementary evidence / diagnostic test |
| 具体性 | 停在「nonexclusive」抽象限定 | 指明哪条补充分析与哪条机制不相容/不分离 |

## 何时会再犯

- 写补充分析收束、要区分「确认」与「相容」时，用 `adjudication` / `nonexclusive` 作元句。
- 目标期刊画像「元句容受」列未标注为允许时，一律按默认转为论文语言。
