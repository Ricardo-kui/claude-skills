## 形状指纹

跨单位的结构性条件改变行动者的目标或外部性权重 → 产生双边际治理结果 → 边界条件由该结构机制本身推出（不外包给情境变量）。
段落形状：**P1** 裁量空间→结构条件 · **P2** 内部治理→外部压力→所有权条件 · **P3** 对立机制→裁定 · **P4** 一个构念统摄两条边界 · **P5** 量级+一次集中边界披露 · **P6** 理论问题转换+实践/政策收束。
适用条件：① 同一前因被结构条件分派到 ≥2 个决策边际（count 与 timing 之类），而非单边际增强；② 结构条件跨单位成立（外部治理者/关联单位之间），不是单位内部属性；③ 能点名 closest paper 并指出其 focal-firm premise；④ Gap 以 Incompleteness（可带 Mechanism）为主。本形状只提供段落与底本，不反推故事类型（见 `references/library-contract.md` 边界 2）。

## 段落序列 P1–P6

### P1 Hook：先立裁量空间，再引入结构性条件

- 主导功能：Framing——先说结果记录的是"裁量如何转化"，再引入跨单位结构条件。
- 承载信息：结构性条件 / 双边际结果 / 裁量来源。
- 底本：
  - `模板` — ball_2018 / wowak_2020_female_directors_recalls：
    > “A fundamental premise of [safety regulation] is that firms will convert known defects into timely corrective action. [Actor discretion] complicates this premise. Firms choose [design, investigation, initiation]. The [outcome] therefore reflects [more than incidence]; it also records [conversion into public action].”
  - `verbatim` 索引 id（本段功能）：
    - `03-data-shock#3`（darby2025）— 裁量空间：企业自行决定何时启动召回
    - `03-data-shock#8`（lu2022）— 跨单位条件 + 行为轶事（共同所有权 → 后续动作）
  - 缺口：ball_2018 与本形状 Hook 位的 Wowak MSOM 底本在本库**无 verbatim 锚**，只有上方 `模板`。

### P2 Literature turn：内部治理 → 外部压力 → 所有权条件

- 主导功能：Literature turn——把文献视野从内部治理推到外部压力，再落到所有权这一结构条件。
- 承载信息：closest paper / focal-firm premise / 本文结构条件。
- 底本：
  - `模板` — darby2026 + hoffmann2024：
    > “Research on [recall governance] has largely been limited to [internal decision makers]. Recent work has begun to extend this view to [external pressures]. [Closest paper] show that [their finding], but their account retains a [focal-firm premise]. [Our structural condition] complicates that premise because [outcome redistributes value across units].”
  - `verbatim` 索引 id（本段功能）：
    - `03-disciplinary-gap-stakes#1`（darby2026）— 只盯内部治理的短视
    - `02-actor-funnel#1`（darby2026）— 外部投资者进入供应链议题
    - `02-actor-funnel#2`（darby2026）— 投资者对各重大决策有话语权
    - `02-actor-funnel#3`（darby2026）— broad 类属 → 具体子集的异质性论证

### P3 Theory lens：先摆对立机制，再给裁定

### P6 Contribution：理论问题转变 + 实践/政策收束

- 主导功能：Contribution——把问题从"能力多大"改成"谁的价值进入治理计算"，再收实践与公共政策（有界）。
- 承载信息：capacity question → objective question / explaining literature / bounded implication。
- 底本：
  - `模板` — hoffmann2024 + darby2026：

We also extend [explaining literature] by showing [when the condition has force]. For practice, [implication]. For public policy, [bounded implication].”
  - `verbatim` 索引 id（本段功能）：
