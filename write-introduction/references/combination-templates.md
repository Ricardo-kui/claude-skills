# Combination Templates

Use this reference when the user requests a specific Gap type × Contribution dimension combination.

## Combination 1: Incompleteness + Mechanism

> **Exemplar**: Wu 2025 (stakeholder activism → proactive self-regulation mechanism gap)
> **Narrative tension**: Progressive omission

**Paragraph function map**:
| Paragraph | Function | Words | Required |
|-----------|----------|-------|----------|
| P1 | Background / cold-start definition | 50-90 | ✅ |
| P2 | Literature review (Progressive Coherence) → mechanism gap | 40-80 | ✅ |
| P3 | Theoretical lens introduction (Drawing on...) | 60-100 | ✅ |
| P4 | Mechanism preview + identification strategy | 80-140 | ⚠️ |
| P5 | Findings preview | 60-90 | ✅ |
| P6-P7 | Contribution statements (literature shift + mechanism identification) | 70-110 each | ✅ |

**Problematization templates**:
1. "Despite the progress made in [area], the question of how [X] leads to [Y] has gone largely unaddressed."
2. "Although researchers have extensively studied [topic], the mechanism through which [X] affects [Y] remains unclear."
3. "While prior work has focused on [dominant perspective], [specific mechanism] has received limited attention."

**Risk reminder**: Must explain why this mechanism's absence is a theoretically important omission, not just "few studies have examined."

| Paragraph | Function | Words | Required |

| P5 | Findings preview | 60-90 | ✅ |
| P6 | Contribution statement (construct refinement) | 70-110 | ✅ |

**Problematization templates**:

## Combination 5: Inadequacy + Boundary

> **Exemplar**: Han 2020 (status × category proximity boundary condition)
> **Narrative tension**: Perspective blind spot

**Paragraph function map**:
| Paragraph | Function | Words | Required |
|-----------|----------|-------|----------|
| P1 | Consensus + core gap | 60-100 | ✅ |
| P2 | Decontextualization critique | 60-100 | ✅ |
| P3 | Theoretical solution preview (boundary condition) | 70-120 | ✅ |
| P4 | Empirical setting + findings preview | 60-100 | ✅ |
| P5 | Contribution statement (importance of contextual factors) | 70-110 | ✅ |

**Problematization templates**:
1. "Research has consistently found that [core finding]. Apart from [dominant factor], however, [phenomenon]'s antecedents are poorly understood as they have received remarkably little research attention."
2. "Further, most research on [topic] has treated [construct] as decontextualized. This is also problematic because the context in which an event or action occurs can differentially shape assessments and responses."
3. "We disentangle these divergent views and offer a clearer understanding of when and how [phenomenon] leads to each dynamic by exploring how [factor] inside and outside [boundary] each shape [outcome]."

**Risk reminder**: Must explain why "decontextualization" is problematic; cannot just say "context matters."

## Combination 7: Incommensurability + Constructs

> **Exemplar**: Pontikes 2012 (challenging "ambiguous categories are harmful" consensus, reconstructing audience role)
> **Narrative tension**: Consensus overturn

**Paragraph function map**:
| Paragraph | Function | Words | Required |
|-----------|----------|-------|----------|
| P1 | Literature consensus establishment | 60-100 | ✅ |
| P2 | Counterexample / contradiction identified | 70-100 | ✅ |
| P3 | Theoretical solution (construct reconstruction) | 70-120 | ✅ |
| P4 | Empirical setting | 60-90 | ✅ |

**Problematization templates**:
1. "Researchers are becoming increasingly interested in [topic]. [Core finding]. A consensus is building that [claim]. This has been demonstrated in [context 1], [context 2], and [context 3]. It seems that [generalization]."
2. "Despite this, in many contexts, [actor] continue to [action]. This is especially evident in [industry], in which [specific behavior]. If [core assumption], then how does [phenomenon] come to be?"
3. "There are at least two roles for [actor] in a [context]: '[role A],' who [description A], and '[role B],' who [description B]. Thus the way [phenomenon] is regarded depends on the perspective of the person evaluating [object]."

**Risk reminder**: Consensus must be real, with sufficient literature support; challenge must be anchored in evidence, not straw men.

## Combination 9: Incommensurability + Boundary

> **Exemplar**: Zhou 2017 (institutional logic + efficiency logic boundary condition); Park 2025
> **Narrative tension**: Consensus overturn

Same paragraph map as Combination 8, but P4 emphasizes how boundary conditions reconcile / modify the scope of the two opposing theories.

**Problematization templates**:
1. "A long-standing debate in [field] centers on whether [claim A] or [claim B]. However, these perspectives have treated [context] as uniform, overlooking how [boundary condition] shapes the relative validity of each theory."
2. "We suggest that the disagreement between [theory A] and [theory B] can be reconciled by identifying [context] as a key boundary condition."
