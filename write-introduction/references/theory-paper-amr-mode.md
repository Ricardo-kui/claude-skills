# Theory-Paper (AMR) Mode — Barney (2018) 三段定位框架

> **何时加载**：Phase 1 判定论文类型 = 理论论文（AMR / AMR 风格，无实证检验）时读取本文件。理论论文模式**覆盖默认实证路由**——不使用实证 Preview（empirical setting / finding direction / methodology defense），改用论证预告。
> **来源**：Barney, J. (2018). Editor's comments: Positioning a theory paper for publication. *Academy of Management Review*, 43(3), 345–348.（editorial / principle source，非范文）

## 核心原则

理论论文引言目标单一：**让读者清楚看到论文解决了一个重要的理论问题**。Barney 的三段框架把这一目标拆成三个功能锚点，每段一个。

与实证论文的关键差异：
- **长度**：~1.5 页（实证 ~3 页）。短几乎总比长好。
- **首句**：点名"加入哪场学术对话"——理论论文通常以对话定位开头，而非现象描述。即便从现象起笔，语言也要迅速转向解释该现象的理论。
- **Preview**：预告"理论论证如何展开"，不是实证方法 / 发现。
- **贡献**：单一核心理论贡献应**自明**，不罗列多个贡献（见 `contributions/_index.md` 变体 O）。
- **RQ**：单一核心研究问题。2+ 个 RQ 通常意味着你其实没有一个核心理论问题。

## Barney 三段框架 — Paragraph Function Map

| 段落 | 功能锚点 | 词数 | 必需 | Barney 硬约束 |
|------|---------|------|------|--------------|
| **P1 首句** | 点名加入的学术对话 | 30–50 | ✅ | 一句话说清"加入哪场对话"；理论论文以对话定位开头 |
| **P1 余下** | 2–3 句提炼对话的主要传统与结论 | 60–100 | ✅ | 提炼本质，非文献清单——"有台电脑就能列长清单，与能在两三句里提炼本质是两回事" |
| **P2 首词** | 转向未解决的理论问题 | — | ✅ | 通常一个"然而 / However"即可 |
| **P2 余下** | 识别理论问题 + 说明为什么是**这一个** | 80–120 | ✅ | **"过去没人研究过"不可接受**——任何理论周围都有成千上万未研究的问题 |
| **P3 首句** | 抛出单一核心 RQ | 20–40 | ✅ | "本文的目的是……"——简单、直接、短；说不清一句 = 你还不理解自己的 RQ |
| **P3 余下** | 预告答案 + 少数关键含义 | 60–100 | ✅ | 不概括全文论证——"若一段能概括全文，那它多半不是充分发展的论证" |

## 模块映射：实证 7 模块 → 理论论文

理论论文不删除功能模块，但重新分配段落预算：

| 实证模块 | 理论论文中的处理 |
|---------|----------------|
| **Hook** | = P1 首句"点名对话"（理论论文的 Hook 即对话定位，不需要 paradox/trend 抓手） |
| **Literature Turn** | = P1 余下 2–3 句提炼（极压缩；不独立成段） |
| **Tension** | = P2（"然而" + 未解决的理论问题 + 为什么是这一个） |
| **Stakes** | 嵌入 P2 末尾（"为什么这个理论问题重要"即理论 Stakes；理论论文通常无独立实践 Stakes 段） |
| **Theory Lens** | = P3 预告的"答案"（核心理论主张） |
| **Preview** | = P3 余下"论证如何展开"的预告（**非**实证 setting / findings / methods） |
| **Contribution** | 单核自明，不罗列（见变体 O）；其他含义用几句短句提及，留 Discussion |

## Problematization Templates

### P1 — 点名对话
> "This paper joins the ongoing conversation on [scholarly question / debate]."
> "A central conversation in [field] concerns [question]."

### P2 — 然而 + 为什么是这一个
> "However, [specific unresolved theoretical problem] remains. This question matters because [empirical implication not yet spelled out / boundary condition not identified / relaxing an assumption would change the prediction / implication for another theory has not been discussed]."

**P2 不可接受的开场**（反模式）：
> ❌ "Few studies have examined X." / "X has received little attention."

理由：任何理论周围都有成千上万未研究的问题；必须解释为什么**这一个**重要，而非"没人研究过"。

### P3 — 目的 + 答案
> "The purpose of this paper is to [core RQ in one simple sentence]. We argue that [core theoretical claim]. [1–2 key implications, each one short sentence.]"

## 贡献纪律（理论论文专属）

如果引言写得正确，论文最核心的贡献——即"解决了一个重要的理论问题"——应当**已经非常明显**。此时罗列对其他研究问题、管理实践或教学的多项贡献，只会让读者偏离核心贡献。

- **理论论文**：用变体 O（单核贡献自明型）——不罗列，核心贡献由 Tension + Theory Lens 自明。
- **其他含义**（实践 / 教学 / 对其他问题的含义）：可用几句短句在 P3 末尾提及，但不在引言展开，留 Discussion。
- **实证论文对比**：实证论文罗列 2–3 个贡献是规范（见变体 D / K / L / M / N），但即使罗列，核心贡献也应**先于清单自明**（见 SKILL.md 反模式"核心贡献未自明"）。

## Risk Reminders

1. **不要罗列贡献**：理论论文单核自明（→ 变体 O）。
2. **不要在 P3 概括全文论证**：若一段能概括全文，论证多半不充分。
3. **单一 RQ**：2+ RQ 通常 = 你其实没有一个核心理论问题。
4. **现象 → 理论迅速转向**：即便从现象起笔，语言要迅速转向理论。
5. **长度 ~1.5 页**：先写一稿，删 20%，再删 20%（见 SKILL.md 长度与编辑纪律）。
6. **"没人研究过"不可接受**：P2 必须解释为什么**这一个**理论问题重要。

## 与 Gap×Contribution 组合的关系

理论论文仍有 Gap 类型（Incompleteness / Inadequacy / Incommensurability）和贡献维度（Constructs / Mechanism / Boundary / …）。Barney 框架**不替代**组合分类，而是为理论论文提供**统一的段落骨架**。Gap 类型仍决定 P2 的标志性语言与能量级（problematization 模板见 `../academic-writing-corpus/tensions/_index.md` 与 `_routing_tables.yaml` 的 exemplar anchoring），贡献维度仍决定 P3 答案的理论形态。
