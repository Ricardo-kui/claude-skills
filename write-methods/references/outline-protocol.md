# Outline Protocol — 段级大纲协议（O1–O3）

> **单一事实源**：本文件是 leading word「大纲」（outline）与「来源列」在 write-methods 内的唯一权威定义处。`SKILL.md` 与其余 reference 只引用本协议，不复述其定义。
> **位置**：槽位目录与加载（`design-branches.md` 定序）之后、`generation-protocol.md` G1 借句表之前。上游 = `design-branches.md`（设计类型→槽位顺序）+ `corpus/_skeleton/_index.md`（24 设计类型路由）；下游 = G1 借句表。
> **分工**：槽位**内部**的段落骨架与 QC 见 `slot-*.md`；设计类型变体句式见 `corpus/[设计类型].md`；Methods–Results 边界见 `robustness-menu.md`。本协议只负责**段序列的取材、合成与来源登记**，不复制上述内容。

## 一、大纲是什么

大纲 = 一张四列表，逐段记录「这一段属哪个槽位、承担什么功能、依据什么底本」。一级轴 = 设计类型（24 项，`corpus/_skeleton/_index.md`）。它是槽位确定后的段级产物，是 G1 借句表的准入前提。

| 段/槽位 | 主导功能 | 承载信息 | 来源 |
|---|---|---|---|
| M2 | 样本漏斗 | 起始总体 → 逐步排除 → 最终 N | `panel-ols#7` |
| M2 | 样本年份陈述 | 起始/结束年份、观测窗口 | `framing-exempt` |
| M7 | 估计器选择理由 | 为何 FE 而非 RE | `panel-ols#T4` |
| M8 | 识别策略辩护 | 排他性约束论证 | `self-drafted` |

> 上表为格式示意，不是可套用的段落清单。

**大纲不是**：槽位骨架（`slot-*.md`）、设计类型变体（`corpus/[设计类型].md`）、句子底本（G1/G2 负责）。

## 二、O1 取材

1. 读 `references/design-branches.md`，确定该设计类型的槽位顺序（默认 M1→…→M10 或特殊分支）。
2. 读 `corpus/_skeleton/_index.md`「一级轴 = 设计类型」表，定位该设计类型对应的二级清单文件（24 项之一）。
3. 整份读入二级清单 `corpus/_skeleton/<设计类型>.md`，取「适配槽位」列命中当前槽位的底本 id（`<设计类型>#<N>` / `<设计类型>#T<N>`）。

## 三、O2 合成

1. 把 `design-branches.md` 的槽位顺序展开为段序列（每槽位可拆 1–N 段；M7 公式+文字可拆两段）。
2. **来源列**：每段填二级底本 id 或 `self-drafted`；程序性槽位（§六豁免清单）填 `framing-exempt`。
3. 段内既含论证又含程序性陈述时，拆成两段，或按主导功能判一类（论证优先）。
4. 每段「主导功能」取自 slot 文件的段落职责（M2 样本漏斗 / M7 估计器选择 / M8 识别辩护…）。

## 四、O3 登记

1. 逐段登记四列表，每段「来源」非空且取值合法（§五）。
2. `self-drafted` 段如实记录占比，并登记语料变体需求（登记去向见 `generation-protocol.md` G1，不在此复述）。
3. 跳过/压缩的槽位在对应段标 `[skipped: 理由类型]`。
4. 大纲表进入 G1 借句表的准入产物。

## 五、来源取值枚举

| 取值 | 含义 | 何时使用 |
|---|---|---|
| `<设计类型>#<N>` | verbatim 底本 id，取自二级清单「Verbatim 底本」表 | 有逐字底本 |
| `<设计类型>#T<N>` | 模板底本 id，取自二级清单「填槽模板」表 | 有填槽骨架（按填槽处理，不当逐字） |
| `self-drafted` | 无底本，本文自拟 | 前两种来源都无对应 |
| `framing-exempt` | 程序性/审计性内容，不进 coverage 分母 | §六豁免清单 |

## 六、程序性槽位豁免清单（framing 豁免）

以下**审计性内容**填 `framing-exempt`，不进 coverage 分母：

- **样本与数据构建叙述**（M2 起始总体/排除理由+数字/最终 N 漏斗；M9 逐研究程序；实证对象构建的构建步骤）
- **变量定义陈述**（M3/M4/M5 的变量名、操作化公式、测量规则——纯定义部分；该槽位的测量**辩护**仍属论证型，不豁免）
- **伦理/合规声明**（IRB、知情同意、数据使用协议）
- **公式符号与估计器惯例解释**（M7 的公式符号、估计器性质——纯惯例陈述部分）
- **表/附录导航句**

> 判据：这段是否可被审稿人机械核对（数字、年份、变量名、公式符号）而无须理解论证？是 → 豁免；否 → 论证型，需底本 id。

## 七、完成判据（是/否）

- 大纲表四列齐全，每段「来源」非空且取值合法？
- `self-drafted` 占比已如实记录？
- 程序性内容已按 §六填 `framing-exempt`，未混入 coverage 分母？
- 每个跳过/压缩决策在段内标注 `[skipped: 理由类型]`？
- 槽位顺序与 `design-branches.md` 一致（含分支调整理由）？
