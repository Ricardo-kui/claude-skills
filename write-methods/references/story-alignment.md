# Methods Story Alignment

Methods does not become persuasive by sounding literary. It becomes part of the story when the design can resolve the paper's promised questions credibly.

Before rendering M1–M10, build:

| Storyline | Hypotheses | Constructs | Variables or evidence | Model or analytic step | Identification / validity burden | Status |
|---|---|---|---|---|---|---|
| S1 | H1 | | | | | testable / partial / blocked |

Rules:

- `testable`: the design can deliver the promised resolution if its stated assumptions hold.
- `partial`: the design answers only part of the storyline; narrow the promise or add evidence.
- `blocked`: no valid mapping exists; do not generate a polished Methods section.
- A variable name is not sufficient mapping unless its operationalization represents the declared construct.
- Controls must answer a competing explanation, not merely satisfy convention.
- Robustness tests support credibility but do not replace identification.
