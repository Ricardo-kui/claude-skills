# 计数模型 — Results 骨架

## 主骨架

参见 `write-results/SKILL.md` → 填空段落骨架 → `计数模型`。

## 证据节奏摘要

- **Negative binomial IV FE**: 系数→方向解释→经济显著性 (1 SD → N-unit change in count)
- **与 OLS 的关键区别**: 不报告 R²，报告 Wald χ²；不报告 beta 的经济显著性，报告 predicted change in count
- **经济显著性**: predicted count change per SD (而非 elasticity 或 IRR)
