## 证据节奏摘要

- **Negative binomial IV FE**: 系数→方向解释→经济显著性 (1 SD → N-unit change in count)
- **与 OLS 的关键区别**: 不报告 R²，报告 Wald χ²；不报告 beta 的经济显著性，报告 predicted change in count
- **经济显著性**: predicted count change per SD (而非 elasticity 或 IRR)

## 诚实边界

- **显著但实际效应小必须显式降调**：交互项或主效应统计显著但实际效应过小时，必须在正文显式降调（"does not appear to be particularly meaningful in practice"），不得仅以显著性宣布支持。（变体14）
- **null 主效应符号反转只作推测框架**：null 主效应若符号反转并读作"同一构念的另一极"，只作推测框架并推迟到 Discussion（"suggesting that the effect may manifest in a different manner"），不得声称支持。（变体15）
- **R9 综合不得改写 null**：混合结果综合句中 null 不得被包装为支持；"effects differ for different stakeholders" 须由支持+不支持对比共同支撑。（变体16）
- **marginal 交互须显式标 marginal**：交互项 p<.10 必须标 "marginally significant"，不得与 p<.05 同列全支持。Fini 2017 H2a/H3b 线性交互 p<.10 仍称 "consistent with hypothesis"，诚实但须保留 marginal 标签。（变体17/18/19 来源）
- **替代操作化 null 作机制裁决须排除低功效**：同 IV 替代操作化 null 用于支持主机制前，须先排除低功效/测量噪声替代解释，只作推测性裁决（"We interpret this finding as discounting X..."），不升级为确证证据。（变体19）
- **访谈只作机制三角验证**：访谈证据只 corroborate 机制解释，不识别效应；量化曲线 + 匹配 + 替代估计器测 selection/estimator threat，访谈不得把相关性升级为因果机制证明。（变体20）

## 反模式

- **稳健性电池纯枚举条目**：稳健性电池中纯枚举条目（alternative specs 的 iv 条）未逐条 threat 定位——应每项带 "concern that ..." 定位句。（变体17 来源 Fini 2017）
- **曲线调节只报交互符号**：曲线调节只报交互项符号/显著性而不报转折点位置移动与预测计数幅度——须报告曲率/峰高/转折点位置的改变 + 预测计数幅度翻译。（变体18 来源 Fini 2017）
