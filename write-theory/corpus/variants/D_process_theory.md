# 变体 D：质性/过程理论型

> **适用**: 质性研究、归纳研究、过程模型论文
> **范文**: Lashley & Pollock 2020, Pontikes 2012
> **最佳期刊**: ASQ ⭐⭐⭐⭐⭐ | AMR ⭐⭐⭐⭐⭐ | OS ⭐⭐⭐⭐

---

## 段落功能地图

> **定性 vs 定量差异**: 定性/归纳型过程理论论文（如 Lashley & Pollock 2020 OS, Pontikes 2012 ASQ）的 Theory 部分通常包含独立的文献回顾子节，以建立过程视角的理论基础。定量假设检验型论文则将文献回顾嵌入构念定义和 why-chain 推导中，不以独立子节出现。

| 段落 | 功能 | 推荐词数 | 必须度 |
|------|------|----------|--------|
| P1 | 核心构念界定（引用经典定义）+ 过程视角定位 | 80-150 | ✅ |
| P2-P3 | [定性论文] 文献回顾子节：合成已有研究发现，建立过程模型的理论地基。定量论文中此功能嵌入在 P1 构念定义和 P4 过程模型预览中 | 各 60-100 | ⚠️ 定性=是 / 定量=嵌入 |
| P4 | 过程模型预览（"We develop a process model of..."） | 60-80 | ✅ |
| P5-P7 | 过程阶段推演（Stage 1 → Stage 2 → Stage 3...） | 各 70-120 | ✅ |
| P8-P10 | 命题陈述（而非正式假设）——最后命题通常完成 Theory；若阶段关系仍不自明，可追加最短必要的整合来恢复过程连贯性 | 由命题复杂度决定 | ✅ |

> **注意**：管理学顶刊不要求独立 Closure。默认以最后命题自然结束；仅当多个阶段或命题需要重新连接为一个过程模型时，允许在末段嵌入或紧随其后加入最短必要的 integrative synthesis。该 synthesis 不得引入新构念、新命题或新贡献。

## 关键句式模板

**过程视角定位（P1，1-2句）**：
```
"While prior research has focused on [static aspect], we argue that [phenomenon] 
unfolds through a dynamic process. We develop a process model that explains how 
[actor] moves from [initial state] to [final state] through [N] stages."
```

**文献回顾子节（P2-P3，定性/归纳型论文使用）**：
```
"Prior research on [phenomenon] has suggested [dominant view 1] ([citations]). 
[Elaboration on view 1]. [Dominant view 2] ([citations]). [Elaboration on view 2]. 

These streams of research have established that [synthesized knowledge about 
the phenomenon]. Building on these foundations, we develop a process model 
that explains how [phenomenon] unfolds over time through [N] stages."
```
> 文献回顾子节的功能是**合成已有知识作为过程模型的理论地基**，而非重复 Introduction 的 gap statement。结尾应收束到"基于这些基础，我们构建过程模型"，而非"现有研究忽视了 X"。定量论文中文献回顾嵌入 P1-P4 构念定义和模型预览中，不需要独立的文献回顾子节。

**过程模型预览**：
```
"We develop a process model of [phenomenon] that unfolds across [N] stages: 
[Stage 1], [Stage 2], and [Stage 3]. This process is shaped by [contextual factor], 
which determines whether [contingency]."
```

**阶段推演**：
```
"We propose that [Stage 1] is triggered by [condition]. During this stage, 
[actors] engage in [actions], which in turn create the conditions for [Stage 2]. 
The transition from [Stage 1] to [Stage 2] occurs when [threshold/condition]."
```

**命题陈述**：
```
"Proposition [N]: In [context], [actor]'s [action/characteristic] leads to [outcome], 
mediated by [process mechanism]."
```

## Lashley & Pollock 2020 型：核心污名降低三阶段过程模型

**新增于**: write-theory 3.2.0 (Lashley & Pollock 2020 ASQ 蒸馏)

**适用**: 研究无法通过个体解耦去除的核心污名化类别，如何在类别层面通过集体意义重构降低污名。

**过程模型**:
```
[Phase 1: Initiating a Moral Agenda]
行业行动者挪用被压制但文化中可用的叙事/标签，并将其锚定到广泛共享的价值。
触发事件由外生事件（法律判决、公共卫生危机）激活，创造紧迫性与合法性。
通过将类别框架化为（例如）"医疗/同情"，建立情感连接，使新类别与污名化前身区分。

[Phase 2: Moral Prototyping]
类别进入原型化阶段。行动者通过认同正向价值类别、反认同污名化类别，构建新的道德原型。
前台：用新标签替代旧标签，用证言/符号/实践人性化类别。
后台：个体企业为了生存继续从事被新原型公开谴责的行为。
侧台：公开但混乱的谈判，暴露原型边界冲突。

[Phase 3: Morality Infusion]
原型凝聚后，行动者引入物质变化（展示实践 / 稀释实践），使原型可感知、可接近。
通过本地社区嵌入和更广泛的行业协会/游说/媒体传播扩散原型。
后台生存违规行为持续，集体形象与个体资源获取之间的张力贯穿始终。
```

**关键转折逻辑**:
- 触发点由外部逐渐转移到内部
- 叙事/符号边界工作必须先于物质变化（污名化类别的反向涌现顺序）
- 关系空间分离（前台/后台/侧台）是维持集体去污名目标与个体生存需求共存的关键机制

**命题模板**:
```
Proposition [N]: In [context], [collective action] leads to [outcome], mediated by [process mechanism].
```

**范围条件**:
- 污名是核心/身份导向的，而非事件导向的
- 类别成员无法轻易切割或退出污名化身份
- 污名是道德/社会的，而非物理的
- 存在足够强的反价值可替代原有污名价值

## QC 检查点

- [ ] 命题是否表达了清晰的理论关系（而非描述性观察）？
- [ ] 过程模型是否包含了 transition/contingency 逻辑（而非只是阶段列表）？
- [ ] 阶段 marker 是否是当前阶段产生、且在下一阶段核心行动前可观察的证据，而非下一阶段的首个行动？
- [ ] 反馈是否明确区分 source、carrier/channel、translation 与有决策权的 recipient？
- [ ] 是否区分了 necessary conditions 和 sufficient conditions？
- [ ] 理论化是否与我们观察到的 empirical variation 一致？
- [ ] 最后命题是否自然收束？若阶段关系仍不自明，整合是否只保留恢复过程连贯性所必需的内容，且没有新增理论内容？
